# Automate the Boring Stuff — Projects

Working through Al Sweigart's *Automate the Boring Stuff with Python*, chapter by chapter. Each folder holds the book's exercises plus a lot of extra mini-projects I set myself once I get curious about a topic — which is most of the time.

---

### Chapters

| Chapter | Covers | Projects |
|---|---|---|
| 02 — Flow Statements | Loops, conditionals, basic input validation | 11 |
| 03 — Functions | Writing and structuring reusable functions | 11 |
| 07 — Dictionaries | Nested data, lookup tables, dedup, comprehensions — this one got out of hand | 94 |
| 08 — Strings | String methods, formatting, text processing | 30 |
| 09 — Regex | Pattern matching, validators | 15 |
| 10 — File I/O | Reading/writing files, basic log analysis | 15 |
| 11 — Organizing Files | File sorting, backups, a proof-of-concept zip bomb generator (for science) | 12 |
| 12 — CLI Programs | `argparse`, building actual command-line tools | in progress |

---

### Setup

Python 3, standard library only — nothing to install.

```bash
git clone https://github.com/Hexlow-0/ATBS-Projects.git
cd ATBS-Projects/Automate\ the\ Boring\ Stuff
python3 "Chapter 2 Flow Statements/Chapter 2 Project 1 (Guess the number).py"
```
